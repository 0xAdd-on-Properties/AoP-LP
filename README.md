# AddonProp - Complete Property Ecosystem

A comprehensive property marketplace platform built with React, TypeScript, and Tailwind CSS, featuring sustainable construction, eco-friendly properties, and smart real estate solutions.

## 🌟 Features

### 🏠 **AEco (Ecosystem)**
- Complete property ecosystem landing page
- Green-themed sustainable construction focus
- Interactive hero section with rotating cards
- Comprehensive feature showcase

### 🏘️ **AoP (Property Marketplace)**
- Blue-themed property marketplace
- Buy, Sell, Rent functionality
- Advanced search and filtering
- Property digitization and tokenization
- Virtual tours and AR/VR integration

### 🌱 **AoPEco (Eco Properties)**
- Green-themed sustainable properties
- Earthships, Mandala Homes, Eco Communes
- Smart Apartments and sustainable living
- Environmental impact tracking

### 🛒 **AoPM (Marketplace Aggregator)**
- Elegant black/grey themed marketplace hub
- Property Marketplace
- Sustainable Properties
- Materials Marketplace
- Furnishings Marketplace
- Sustainable Technologies
- Sustainable Systems

## 🚀 Tech Stack

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS + DaisyUI
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **State Management**: React Hooks

## 🛠️ Development

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/shiva-karan-k/AoP-LP.git

# Navigate to project directory
cd AoP-LP

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
npm run build
```

## 🌐 Deployment

The application is optimized for deployment on Vercel with automatic builds from the main branch.

### Vercel Configuration
1. Connect your GitHub repository to Vercel
2. Set build command: `npm run build`
3. Set output directory: `dist`
4. Configure custom domain: `addonprop.xyz`
